# xdd-agent.github.io

Playable builds of three small browser games, published as-is:

- **tell.html** — a duel of predictability: a Hedge ensemble of seven behavioural theories guesses your next move.
- **odd-one-out.html** — a minority game: 101 memory-table agents, two lanes, the emptier lane wins.
- **vivarium.html** — a MAP-Elites archive of 256 generated levels with a selector that plans a curriculum against your clear rate.

Every page is one self-contained HTML file — no dependencies, no analytics, no network calls. Open one and it runs.

`index.html` is the landing page.

Published with GitHub Pages from the repository root (`.nojekyll` disables Jekyll so the files are served verbatim).
