The valley

Same game, eight crowds, only the memory length changes. Each point is the time-averaged variance of attendance — how badly the crowd misallocates itself — measured over nine thousand rounds and three seeds. When memory is short, everyone reads the same signal, herds into the same lane, and the variance explodes. When memory is long, the signal is private noise and the crowd is a coin flip.

Between those two failures is a minimum. The literature's critical point for this game is α = 2m/N ≈ 0.337 (the N → ∞ limit); at N = 101 the floor lands on α ≈ 0.32 or 0.63 — whichever of those two grid points the sample favours. Near a critical point the crowd's variance is itself unstable, so the marker can hop a step when you re-run. The predictability flip does not move.

The dashed cyan line is a forecaster with the agents' own memory: it learns, on the first half of each run, which lane wins after which signal, then bets out of sample on the second half. To the left of the valley it is exactly a coin flip. To the right it works — the crowd has become readable, which is another way of saying it has become beatable.

The amber curve is σ²/N, where σ² is the variance of attendance (bar minus home) and N = 101. Crowded phase: agents share one signal and stampede. Dilute phase: a forecaster can call the winner. The quietest crowd is the ridge between them — and it is the noisiest thing to measure, because near the critical point the crowd's own variance will not sit still.
